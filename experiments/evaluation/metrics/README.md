# Person 3 - DriftLens vs MCD-DD Comparison and Metrics

## Objective

This module compares DriftLens and MCD-DD using the controlled scenarios generated by Person 2.

The detector outputs are combined using `window_id` and evaluated using known ground-truth drift points.

## Scenarios

- Sudden drift: drift starts at position 30.
- Gradual drift: drift starts at position 30 and ends at position 45.
- Volume change: volume increases by a factor of 3 at position 30 without concept drift.
- No drift: no concept drift and no volume change.

The evaluation uses 14 reference windows and 46 non-reference windows.

## Main Findings

### Sudden Drift

DriftLens detects all expected drift windows with F1 = 1.000 and zero detection delay.

MCD-DD detects the first drift window but misses subsequent drift windows, giving recall = 0.400 and F1 = 0.571.

### Gradual Drift

DriftLens performs strongly with recall = 0.967 and F1 = 0.983, with a detection delay of one window.

MCD-DD produces no alarms in this scenario.

### Volume Change

There is no concept drift.

DriftLens produces one false alarm, while MCD-DD produces no false alarms.

### No Drift

DriftLens produces no false alarms.

MCD-DD produces one false alarm.
